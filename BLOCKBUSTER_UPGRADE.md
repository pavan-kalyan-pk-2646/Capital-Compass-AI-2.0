# Capital Compass AI 2.0 — Blockbuster UI Upgrade

This build preserves the existing financial decision-intelligence backend and upgrades the product experience around it.

## What changed
- Cinematic 3D ambient orbit layer across the authenticated application shell.
- Premium command navigation with active-route glow, depth, motion and grouped decision stages.
- Deep navy / near-black financial theatre background with restrained brass, blue, green, red and amber state language.
- Glass/depth surfaces, animated panel entry, elevated hover states and stronger financial-number hierarchy.
- Upgraded landing experience with a large cinematic title reveal, metallic compass presentation, flare, theatre/vignette treatment and richer story sections.
- Existing Three.js compass intro is preserved and remains the hero 3D moment.
- Responsive and reduced-motion fallbacks are retained.
- No changes to the financial engine semantics or backend decision architecture.

## Quality checks
- `frontend/npm run typecheck` — PASS
- `frontend/npm run lint` — PASS
- Production Vite build could not be executed in the Linux sandbox because the supplied Windows-style dependency archive does not contain Rollup's Linux optional native package. The source itself type-checks and lints cleanly.

## Run
1. Install frontend dependencies: `cd frontend && npm install`
2. Start frontend: `npm run dev`
3. Start backend using the existing project instructions in `README.md`.
